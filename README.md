# UITS Assignment / Lab Report Cover Page Generator

Fill in the form and download a ready-to-print UITS cover page as **Word (.docx)** or **PDF**.

**Live site:** https://minhaz-cant-code.github.io/UITS-Cover-Page-Generator/

- Live A4 preview in the UITS template
- Optional topic heading, assignment/lab number and experiment number
- Remembers your name, ID, semester, batch, section and department in your browser
- Light and dark mode

## Run it locally

No build step or install is needed. Download the repo and open `index.html` in a browser. The Word download needs internet access because it loads the `docx` library from a CDN.

## Known issue

Downloads don't work inside in-app browsers such as Facebook's. Open the site in Chrome, Safari, Edge or Firefox instead.
