# Contributing

Thanks for helping improve the UITS Cover Page Generator.

## Reporting a problem

Open an issue and include:

- what you did and what happened
- your device and browser
- a screenshot, if it helps

Please don't post your real student ID or other personal details.

## Making a change

1. Fork the repo and create a branch.
2. Make your change. Everything is in `index.html`, and it runs without a build step.
3. Check that:
   - the live preview, Word download and PDF / Print still work
   - the cover page still fits on one A4 page
   - the page fits one screen on desktop, with no scrolling
   - the phone layout and dark mode still look right
4. Open a pull request that explains what changed and why.

Please keep each pull request to one change. The maintainer decides what gets merged.
